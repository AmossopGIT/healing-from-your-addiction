# August 2026 blog art prompts

Ready-to-paste image-creator prompts for newly created CMS blogs.

**Status (2026-08-10):** All 14 heroes below were generated, saved under `public/art/watercolor/`, registered in `content/artGallery.ts`, and linked on the matching CMS posts.

**How to regenerate**
1. Paste one prompt into the image creator.
2. Prefer a reference from `public/art/watercolor/` (closest topic match).
3. Save PNG as the filename listed.
4. Put the file in `public/art/watercolor/`.
5. In CMS, set hero art path to `/art/watercolor/[filename]`.

**Shared negative guidance (already in each prompt)**  
Avoid photorealism, neon colors, clutter, logos, readable text, distress, shame, needles, explicit content, medical rooms, casino scenes, alcohol labels, social media logos, detailed faces, cartoon comedy.
