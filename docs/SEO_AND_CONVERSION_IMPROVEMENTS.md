# SEO and Conversion Improvements

## SEO requirements

Every page must have:

- Unique title
- Unique meta description
- One H1
- Proper H2/H3 structure
- Canonical URL
- Open Graph image
- Structured data where useful

## Conversion improvements

- Put the form above the fold on campaign pages.
- Use addiction-specific pain points.
- Add trust before asking for commitment.
- Add CTAs after key sections.
- Include clear confidentiality messaging.
- Track all CTA and contact actions.
- Keep mobile layout fast and direct.

## Google Ads reminder

Do not send gambling ads to a generic homepage when `/addictions/gambling-addiction-help/` exists. Do not send food addiction ads to a generic homepage when `/addictions/food-addiction-binge-eating-help/` exists.
