# Implementation Roadmap

## Phase 1 - Foundation

- Create Next.js project
- Add reusable components
- Add content model
- Build core pages
- Add metadata and schema
- Add tracking helpers
- Add lead form redirect to `/thank-you/`

## Phase 2 - Launch preparation

- Add real WhatsApp and phone environment variables
- Connect `/api/leads/` to secure email, CRM or database
- Configure GTM and GA4
- Configure Google Ads conversion on `/thank-you/`
- Test form submission and all click events
- Check mobile Lighthouse scores

## Phase 3 - Migration

- Configure domain
- Add redirects from old URLs
- Submit sitemap in Search Console
- Monitor 404s
- Monitor indexing and search queries

## Phase 4 - Scale

- Review Google Ads search terms
- Add negative keywords
- Improve ad groups
- Expand future addiction pages using the landing-page template
