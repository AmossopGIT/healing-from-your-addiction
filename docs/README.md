# Healing From Your Addiction Documentation

This folder defines the product, architecture, SEO/conversion strategy, ethical rules, tracking plan and implementation roadmap for the Healing From Your Addiction lead capture website.

Core instruction:

Do not build this like a normal WordPress blog. Build it as a conversion-focused landing page system where every addiction category can become its own SEO and Google Ads landing page.
