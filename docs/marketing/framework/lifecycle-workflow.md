# Lifecycle Workflow

## Standard Operating Flow

1. Define campaign brief in Markdown.
2. Build or clone campaign JSON from template.
3. Validate wording against messaging guardrails.
4. QA keywords, assets, negatives, and tracking.
5. Build in platform.
6. Record launch metadata and baseline metrics.
7. Log weekly and monthly optimisations.
8. Version updates for future iterations.

## Definition Of Done

A campaign is launch-ready when:

- Brief and JSON are both complete.
- Guardrail checks are passed.
- Shared and campaign-specific negatives are linked.
- Conversion events and UTM template are defined.
- Budget, bidding, and geography settings are explicit.
