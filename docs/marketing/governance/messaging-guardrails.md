# Messaging Guardrails

## Core Safety Standard

All ad and landing page copy must support behavioural change without implying guaranteed outcomes.

## Required Language Patterns

- Prefer: `support`, `structured programme`, `may help`, `focused on`, `aim is`.
- Keep tone respectful, non-judgmental, and confidential.
- Frame the offer as guidance and pattern work, not a medical cure claim.

## Restricted Claims

Do not use:

- `cure`, `guaranteed cure`, `permanent cure`, `instant fix`.
- `100% success`, `guaranteed results`, `works for everyone`.
- Any diagnosis-like certainty unless clinically required and legally vetted.

## Programme Positioning Rules

- Present programme duration and structure factually (for current campaigns: 8-session programme).
- Avoid fear-based or shame-based language.
- Avoid overclaiming practitioner scope.
- Include private/confidential framing where suitable.

## Compliance Check Before Launch

Every campaign must pass these checks:

1. No guaranteed result claims.
2. No cure language.
3. No unverified medical promises.
4. Clear support-oriented wording.
5. Landing page message consistency with ad copy.
