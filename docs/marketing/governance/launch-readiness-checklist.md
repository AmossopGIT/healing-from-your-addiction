# Launch Readiness Checklist

Use this checklist before any campaign goes live.

## 1) Message And Compliance

- [ ] No `cure`, `guaranteed`, `instant fix`, or certainty claims.
- [ ] Wording frames support, behaviour patterns, and structured guidance.
- [ ] Ad copy and landing page copy match in promise and tone.
- [ ] Language remains non-judgmental and confidentiality-oriented.

## 2) Campaign Settings

- [ ] Campaign naming follows standard: `HFYA | <Channel> | <Topic> | ZA`.
- [ ] Location set to South Africa.
- [ ] Search campaigns use Google Search only for initial test phase.
- [ ] Search partners and display expansion off for initial test phase.
- [ ] Bidding strategy and daily budget explicitly set.

## 3) Build Completeness

- [ ] Ad groups are intent-specific and tightly themed.
- [ ] Phrase-match seed keywords are loaded by ad group.
- [ ] Shared negative list applied.
- [ ] Campaign-specific negative list applied.
- [ ] Shared assets (callouts, snippets, sitelinks) attached.
- [ ] Pinning is limited to required headlines only.

## 4) Tracking And Measurement

- [ ] UTM template applied.
- [ ] Conversion events configured: form submit, phone click, WhatsApp click.
- [ ] Primary conversion goal selected.
- [ ] Thank-you/lead confirmation flow tested.

## 5) Documentation Quality Gate

- [ ] Campaign Markdown brief updated.
- [ ] Campaign JSON payload updated.
- [ ] Shared assets/negatives references are correct.
- [ ] Monthly performance file template prepared for reporting period.

## 6) Approval

- [ ] Internal QA completed.
- [ ] Final sign-off recorded with date and owner.
