# Cursor Build Prompt

Build Healing From Your Addiction as a modern SEO-focused lead capture website, not a normal WordPress blog.

Use Next.js, React, TypeScript, reusable components, server-rendered metadata, schema markup, a reusable lead form, thank-you page conversion tracking, dataLayer events and mobile-first UX.

Core pages:

- Home
- Gambling Addiction Help
- Food Addiction / Binge Eating Help
- About Gerald Crawford
- Addiction Healing Programmes
- Contact
- Thank You

Lead form fields:

- Full name
- Email
- Phone / WhatsApp number
- Addiction concern
- Preferred contact method
- Message
- Consent checkbox

After successful form submission, redirect to `/thank-you/` and push `lead_form_submit` to the dataLayer.

Track WhatsApp, email, phone, CTA, programme card, FAQ and form-start events.

Do not claim to cure addiction, guarantee results or replace medical detox, psychiatric treatment, emergency care or licensed rehabilitation.
