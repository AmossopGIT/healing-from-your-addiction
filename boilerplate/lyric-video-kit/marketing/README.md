# Marketing — lyric video campaigns

Portable templates for blog-song lyric videos. Copy `campaigns/_template/` when starting a new article.

| File | Purpose |
|------|---------|
| [workflow.md](./workflow.md) | Production steps, loop-v5, dual export |
| [messaging-guardrails.md](./messaging-guardrails.md) | Copy safety (no cure/guarantee claims) |
| [QUEUE.template.md](./QUEUE.template.md) | Pipeline table for your project |
| `campaigns/_template/` | CAMPAIGN, social publishing, LYRICS-SOURCE templates |

## Per campaign

1. `LYRICS-SOURCE.md` — lock lyrics, audio, Whisper, SRT QA
2. `CAMPAIGN.md` — production record and asset paths
3. `social-publishing.md` — platform titles and descriptions

Horizontal → YouTube / Facebook. Portrait → TikTok / Reels / Stories.
