# Marketing — social video distribution

Portable templates for distributing loop-v5 masters to social platforms.

| File | Purpose |
|------|---------|
| [workflow.md](./workflow.md) | Five-step distribution flow |
| [platform-specs.md](./platform-specs.md) | Dimensions, safe zones, clean vs hook |
| [messaging-guardrails.md](./messaging-guardrails.md) | Copy safety checklist |
| `campaigns/_template/` | CAMPAIGN, HOOKS, social-publishing templates |

## Per campaign

1. `CAMPAIGN.md` — sources, config path, manifest location
2. `HOOKS.md` — timed hooks, burn-in vs native
3. `social-publishing.md` — asset matrix, titles, captions

Horizontal → YouTube / Facebook landscape / LinkedIn.  
Portrait → TikTok / Reels / Shorts.  
Crops → Instagram / Facebook feed (1:1, 4:5).
